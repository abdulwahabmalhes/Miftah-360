# Miftah 360 - Shared Configuration (`packages/config`)

## Ownership
- **Owner**: Lead Architect & Backend Core Agent
- **Supervision**: Lead Architect & Orchestrator

## Purpose
Houses shared configurations across the monorepo to ensure consistency, type safety, and clean code standards:
- Base `tsconfig` configurations.
- Shared ESLint & Prettier configs.
- Shared Tailwind / Design Token definitions (Miftah 360 Brand colors, typography, RTL utilities).
- Environment variable validation schemas (using Zod / Joi).
